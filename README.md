# Essenza

Tienda online (HTML estático) conectada a Supabase.

- Sitio público: `index.html`
- Panel de administración: `tu-dominio/#admin`
- Base de datos: proyecto Supabase `essenza`

## Despliegue
1. Subir este repositorio a GitHub.
2. En Vercel: Add New → Project → importar el repositorio.
3. Framework Preset: **Other**. Sin comando de build ni carpeta de salida.
4. Deploy.
